## 2026-11-15 — lgwks_bot 9.0.0: one typed error per layer

- #990 (PR #1063, ADR 0061): each layer raises its own typed error and a lower
  layer never names an upper one. The kernel, the world, the session and the
  script own `KernelError`, `EcsError`, `SessionError` and `FlowError`. The app
  layer's `BotError` is their sum, with `From` for each. The rule
  `INV-ERROR-LAYER-1` holds the layering. The `core_boundary` test refuses a
  kernel module that names the world, the session or the stability monitor.
- Release cut: lgwks_bot 9.0.0
  ([notes](../changelog/23-one-typed-error-per-layer-2026-11-15.md)). A major
  bump, because a consumer `match` on a `BotError` variant that moved no longer
  compiles. Every field and every `Display` text is kept, and `retry_class`
  answers the same on every layer.
- Receipts: the manifest, the workspace pin, the lockfiles and the changelog
  row agree on lgwks_bot 9.0.0 (`changelog_rows`, `sim_agent_start_page`).
- **Not claimed**: a published crate. The row records the manifest, not a
  release upload.

# lgwks_bot 8.0.1

Released 2026-11-08. A consumer can now select `edge` on its own.

## lgwks_bot 8.0.1 (patch)

- `default-features = false, features = ["edge"]` did not compile, because `app` and `rt::serve` import `task` and `script`, which only `script` enabled. `edge` now carries `script`. A consumer who enabled both as a workaround can drop `script`, and no item changes.

The `lgwks` command part of the repository's invariant register; the rest is in [`INVARIANTS.md`](../../INVARIANTS.md). One line per rule: rule, why, enforced by.

- **INV-LGWKS-NEW-1** `lgwks new` writes exactly `Cargo.toml` and `app.rs` and refuses a non-empty directory rather than clobbering it. · why: #787 · enforced by: `tests/it/lgwks_e2e.rs::new_check_expand_run_serves_one_request` (asserts the two files and nothing else) and `tests/it/lgwks_json.rs::new_json_is_parseable`
- **INV-LGWKS-CHECK-1** `lgwks check` runs the one parser plus the `PlanLimits` bounds without building, with `line:col` refusals, a did-you-mean over the script vocabulary, and the bound to add for unbounded constructs. · why: #787 · enforced by: `tests/it/sim_lgwks_check.rs` (`typo_suggests_the_right_word`, `unknown_word_without_a_neighbor_is_malformed`, `truncation_is_malformed_never_a_panic`, `unbounded_constructs_name_their_ceiling`, `reference_app_is_admitted`; same verdict per seed)
- **INV-LGWKS-EXPAND-1** `lgwks expand` prints byte-for-byte what the macro compiles through the one emitter, formatted, and the expansion passes clippy with denied warnings. · why: #787 · enforced by: `tests/it/sim_lgwks_expand.rs::expand_replays_its_text` and `::expanded_app_passes_clippy` (pins match the workspace)
- **INV-LGWKS-EMIT-1** One emitter (`lgwks_ast::script::emit::script`); `lgwks_macros` is a thin shell over parse plus that function, never a second code path. · why: #787 · enforced by: `lgwks_macros::tests::expand` (the macro's own path) and `tests/it/sim_lgwks_expand.rs::expand_replays_its_text`
- **INV-LGWKS-RUN-1** `lgwks run` builds twice through cargo in one shared target directory and prints the cold build, the warm rebuild and the spawn-to-accept start. · why: #787 · enforced by: `tests/it/lgwks_e2e.rs::new_check_expand_run_serves_one_request` and `tests/it/lgwks_json.rs::run_json_is_parseable_then_serves`
- **INV-LGWKS-JSON-1** Every command takes `--json` with the same facts as the human text. · why: #787 · enforced by: `tests/it/lgwks_json.rs`

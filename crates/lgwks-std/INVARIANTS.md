# `lgwks_std` legacy codec invariants

The `invariants` lane reads this file with the repository register (`INVARIANTS.md`). One line per rule: rule, why, enforcing test.

- **INV-LEGACY-1** Every `lgwks_std::legacy` codec decodes and encodes, so `decode` then `encode` returns the same bytes; every reader takes a `Limits` and refuses past it with a typed error before allocating; every failure is a typed error naming its offset, never a panic, `unwrap`/`expect` or indexing past `get`. · why: #792, legacy estate formats arrive hostile · enforced by: `tests/it/sim_legacy_ebcdic.rs` (`a_seeded_text_round_trips_through_encode_and_decode`, `hostile_bytes_answer_typed_errors`, `tables_hold_every_byte_and_limits_name_every_ceiling`), `tests/it/sim_legacy_decimal.rs` (`the_packed_layout_matches_its_vector`, `hostile_nibbles_answer_typed_errors`), `tests/it/sim_legacy_copybook.rs` (`a_seeded_record_round_trips`, `hostile_copybooks_answer_located_diagnostics`), `tests/it/sim_legacy_cfb.rs` (`a_seeded_image_round_trips`, `hostile_images_answer_typed_errors`, `vba_source_round_trips_and_refuses_truncation`), `tests/it/sim_legacy_access.rs` (`a_seeded_table_round_trips`, `hostile_images_answer_typed_errors`, `a_table_past_one_page_spans_pages_and_a_table_past_255_is_refused`), `tests/it/sim_legacy_fax.rs` (`a_seeded_bitmap_round_trips_every_compression`, `hostile_strips_answer_typed_errors`) and the same-seed-replay plus distinct-seed-diverge oracles in each file
- **INV-LEGACY-2** The legacy codecs are reachable in one line from `script!`. · why: #792, SD-1 wiring · enforced by: `crates/lgwks-bot/tests/it/legacy_script.rs` (`a_script_flow_calls_the_ebcdic_codec_in_one_line`, `a_script_flow_calls_the_decimal_codec_in_one_line`)
